The country catalog was expanded on 2026-11-08 from the public-domain [DataHub country-codes CSV](https://github.com/datasets/country-codes/blob/main/data/country-codes.csv). `data/countries.json` contains 200 playable countries with no per-phase eligibility exclusions. The catalog covers the 193 UN members, the two observer states, Western Sahara, Kosovo, Taiwan, Cook Islands and Niue. Kosovo has the explicit application geometry ID `XKX`, not an ISO numeric code. Source details and capital conventions are recorded in `data/SOURCES.md`.

`data/geometry-supplements.json` contains 37 small-country geometries extracted from [Natural Earth 5.1.2 admin-0 countries at 1:10m](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_10m_admin_0_countries.geojson), including Tuvalu, which is absent from world-atlas at 1:50m. The Natural Earth geometries are public domain. Monaco and Vatican City are subsequently replaced with detailed geoBoundaries features as described below. All source polygons are retained. Duplicate source records for Australia are grouped under the same country ID. Morocco and Western Sahara are separated by the explicit game boundary described in the README and sources file.

Other application dependencies include React (MIT), Express (MIT), Socket.IO and socket.io-client (MIT), Zod (MIT), Helmet (MIT), and Lucide (ISC; some incorporated icons have MIT notices). Their upstream notices ship in the installed npm packages. Exact installed versions are pinned by `package-lock.json`.

Borders are generalized cartographic data for a recreational quiz. Silhouettes center the projection away from the date line, retain all represented territory, and add an enlarged detail alongside the full-country view when distant islands would make the shape unreadable. No country is excluded for this reason. Location rendering and server containment use the same geometry rounded to six decimal places; no distance-based scoring tolerance is added.

Monaco's detailed boundary is © OpenStreetMap contributors, via Wambacher and geoBoundaries (MCO-ADM0-9783051), under [ODbL 1.0](https://www.openstreetmap.org/copyright). Vatican City's detailed boundary is geoBoundaries/Wikimedia Commons (VAT-ADM0-52476719), public domain. Exact pinned source URLs and represented dates are in `data/SOURCES.md`. The combined supplements and derived location-map databases are distributed under ODbL 1.0; the license text is included in `licenses/odbl.txt`. The app credits the sources and provides the derived database and license through `/map-data.geojson` and `/map-data-license`. Generated silhouettes and the globe are produced works using those credited data.
